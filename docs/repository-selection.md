# Repository Selection

Pinned repositories should demonstrate complementary strengths rather than repeat the same type of project.

## Selection criteria

- Clear problem statement and target user
- Working or reproducible implementation
- Tests or validation evidence
- Architecture or design rationale
- Security and operational considerations where relevant
- Useful README with a fast path to evaluation

Prefer a balanced portfolio spanning secure Edge AI, production AI automation, embedded systems, cryptography, and research engineering.

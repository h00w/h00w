# GitHub Achievement Roadmap

This document tracks profile-level GitHub achievements for `@h00w` and keeps achievement-related work separate from the public profile README.

## Targets

- Quickdraw — close an issue or pull request shortly after opening it.
- Pull Shark — merge pull requests.
- YOLO — merge a pull request without a code review.
- Pair Extraordinaire — co-author work that is merged through a pull request.
- Galaxy Brain — provide accepted answers in GitHub Discussions.
- Starstruck — grow a public repository to the required star threshold.
- Public Sponsor — publicly sponsor eligible open-source work through GitHub Sponsors.

The priority is to earn achievements through useful repository maintenance and genuine open-source collaboration rather than artificial activity.

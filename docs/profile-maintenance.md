# Profile Maintenance Notes

A lightweight checklist for keeping the `@h00w` GitHub profile useful and current.

- Keep the profile README focused on current research and engineering work.
- Pin repositories that demonstrate production AI, secure Edge AI, cybersecurity, embedded systems, and applied research.
- Prefer substantive pull requests and documented releases over contribution-count padding.
- Keep project links, demos, CI status, and documentation healthy.
- Use GitHub Discussions and issues for technical knowledge sharing where appropriate.

# Profile Principles

This profile should represent substantive engineering work rather than activity for its own sake.

## Principles

- Keep the public README concise and evidence-oriented.
- Prefer reproducible demos, architecture, tests, and documentation.
- Highlight secure AI, Edge AI, agentic systems, trusted computing, and production engineering.
- Keep claims traceable to public repositories or published work.
- Review pinned repositories periodically and remove stale examples.
